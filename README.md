# Лабораторна робота №6
## Захищений клієнт-серверний застосунок із використанням TLS

### Мета роботи
Закріпити навички створення клієнт-серверної архітектури з використанням SSL/TLS, перевірки зашифрованого з'єднання, аутентифікації користувачів та контролю цілісності переданих даних.

### Опис проєкту
У межах лабораторної роботи розроблено клієнт-серверний застосунок на Python, який забезпечує захищене з'єднання за допомогою TLS.

Сервер виконує:
- встановлення TLS-з'єднання;
- перевірку логіна та пароля;
- перевірку цілісності повідомлення за SHA-256;
- надсилання відповіді клієнту;
- журналювання подій.

Клієнт виконує:
- підключення до сервера;
- перевірку сертифіката сервера;
- передачу облікових даних;
- передачу повідомлення та його SHA-256 хешу;
- отримання та обробку відповіді сервера.

### Технології
- Python 3.10
- SSL/TLS
- SHA-256
- Docker
- Docker Compose

### Запуск
Для запуску серверної частини:

```bash
docker compose up -d server
```

Для запуску клієнта:

```bash
docker compose --profile tools run --rm client
```

### Результати
У ході роботи перевірено встановлення TLS-з'єднання, автентифікацію користувача, контроль цілісності повідомлення та журналювання успішних і невдалих спроб підключення.
